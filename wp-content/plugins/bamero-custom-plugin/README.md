# Bamero Custom Plugin

## توضیحات

این پلاگین سفارشی برای فروشگاه **بامرو** طراحی شده است و ویژگی‌های اختصاصی مانند:
- **فیلترهای پیشرفته** برای محصولات WooCommerce.
- **مشاوره رنگ** از طریق فرم سفارشی.
- **فیلدهای سفارشی** برای محصولات (مثل کد رنگ).

را اضافه می‌کند.

## ویژگی‌ها

### 1. فیلترهای پیشرفته
- فیلتر محصولات بر اساس **نوع محصول** (مثل رنگ، ابزار، و غیره).

### 2. مشاوره رنگ
- اضافه کردن صفحه **مشاوره رنگ** با شورت‌کد `[bamero_color_consultation]`.
- فرم سفارشی برای دریافت درخواست‌های مشاوره.

### 3. فیلدهای سفارشی محصولات
- اضافه کردن فیلد **کد رنگ** به محصولات.
- نمایش کد رنگ در صفحه محصول.

## نصب

1. پوشه `bamero-custom-plugin` را در پوشه `wp-content/plugins/` آپلود کنید.
2. در پنل مدیریت WordPress، به **پلاگین‌ها** بروید و پلاگین **Bamero Custom Plugin** را فعال کنید.

## استفاده

### شورت‌کد مشاوره رنگ
برای نمایش فرم مشاوره رنگ، از شورت‌کد زیر استفاده کنید:
```php
[bamero_color_consultation]
```

### فیلترهای سفارشی
برای فیلتر کردن محصولات بر اساس نوع، از پارامتر `product_type` در URL استفاده کنید:
```
?product_type=color
```

## مستندسازی

برای اطلاعات بیشتر، به فایل `bamero-custom-plugin.php` مراجعه کنید.
