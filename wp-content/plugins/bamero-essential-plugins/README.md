# Bamero Essential Plugins

## توضیحات

این پلاگین برای **نصب و فعال‌سازی خودکار پلاگین‌های ضروری** برای فروشگاه **بامرو** طراحی شده است. با استفاده از این پلاگین، می‌توانید تمام پلاگین‌های مورد نیاز را به صورت خودکار نصب و فعال کنید.

## پلاگین‌های ضروری

| **نام پلاگین** | **Slug** | **وضعیت** | **توضیحات** |
|----------------|----------|------------|--------------|
| WooCommerce | `woocommerce` | ضروری | پلاگین اصلی فروشگاه اینترنتی |
| YITH WooCommerce Wishlist | `yith-woocommerce-wishlist` | ضروری | افزودن لیست علاقه‌مندی |
| WooCommerce Zarinpal Gateway | `woocommerce-zarinpal` | ضروری | درگاه پرداخت زرین‌پال |
| Autoptimize | `autoptimize` | ضروری | بهینه‌سازی CSS/JS |
| WP Super Cache | `wp-super-cache` | ضروری | کش برای بهبود عملکرد |
| Rank Math SEO | `seo-by-rank-math` | ضروری | بهینه‌سازی SEO |
| Wordfence Security | `wordfence` | ضروری | امنیت سایت |
| Contact Form 7 | `contact-form-7` | اختیاری | فرم تماس |

## نصب

1. پوشه `bamero-essential-plugins` را در پوشه `wp-content/plugins/` آپلود کنید.
2. در پنل مدیریت WordPress، به **پلاگین‌ها** بروید و پلاگین **Bamero Essential Plugins** را فعال کنید.

## استفاده

پس از فعال‌سازی پلاگین، تمام پلاگین‌های ضروری به صورت خودکار نصب و فعال می‌شوند. همچنین، می‌توانید از منوی **تنظیمات > پلاگین‌های ضروری بامرو** برای مدیریت دستی پلاگین‌ها استفاده کنید.

## ویژگی‌ها

- نصب و فعال‌سازی خودکار پلاگین‌ها.
- مدیریت دستی پلاگین‌ها از طریق پنل مدیریت.
- پشتیبانی از پلاگین‌های مخزن WordPress و منابع سفارشی.

## نکات مهم

- این پلاگین به **دسترسی ادمین** نیاز دارد.
- برای نصب پلاگین‌ها از مخزن WordPress، سایت شما باید به اینترنت متصل باشد.
- پلاگین **WooCommerce Zarinpal Gateway** از یک منبع سفارشی نصب می‌شود.

## مستندسازی

برای اطلاعات بیشتر، به فایل `bamero-essential-plugins.php` مراجعه کنید.

## امنیت نصب

از نسخه ۱.۱.۰، این پلاگین هنگام فعال‌سازی هیچ دانلود یا فعال‌سازی خودکاری انجام نمی‌دهد. هر نصب باید توسط مدیر دارای مجوز `install_plugins` و با تأیید nonce از صفحه تنظیمات آغاز شود. درگاه زرین‌پال عمداً باید از منبع تأییدشده و مطابق مستندات پذیرنده به‌صورت دستی نصب و پیکربندی شود.
